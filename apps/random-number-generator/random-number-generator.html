Random Number Generator

Overview

This JavaScript app sends requests for the following data in order to generate a random number:

  • Rainfall and temperature values for Blackpool, UK
  • Windspeed and Temerature for Balkhash, Kazakhstan

Both requests are for data from the last 2 days.

See open-meteo.com for more information on the API. Reference for this data source: Zippenfenig, P. (2023) Open-Meteo.com Weather API. Zenodo. doi: 10.5281/ZENODO.7970649.

These two locations should be far enough apart that their weather over the short term are unrelated.

Lots of other API calls to other online resources could be used too: stock markets, the number of days since Github last went down (haha), the time taken for a request...
